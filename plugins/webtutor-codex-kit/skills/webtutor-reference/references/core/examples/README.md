# Проверенные примеры

Каталоги:

- `xquery/`;
- `sql/`;
- `agents/`;
- `remote-collections/`;
- `server-pages/`.

Пример добавляется только если:

1. он мал и не содержит рабочих данных;
2. использует документированные функции;
3. указывает источник и проверяющий тест;
4. не копирует целый production-модуль.

До стабилизации незакоммиченных изменений крупные client-repository файлы не объявляются
«золотыми» примерами. Вместо приблизительной заготовки каталог содержит только
эти правила отбора.
