# Локальная документация и официальные источники

Эта страница связывает локальный практический справочник с исходными статьями `docs.datex.ru`. Для повседневной разработки сначала используйте локальные материалы: они компактнее, доступны без сети и содержат замечания, важные для консервативного WebTutor-кода.

Срез официальной документации и автоматически собранные каталоги обновлены 2026-07-22.

## Обновление локальных каталогов

`generated/` является packaged snapshot официального каталога. Скрипт поиска входит в skill, но сетевой sync-процесс в runtime skill не входит. Обновление snapshot выполняется в исходном marketplace-проекте с сохранением `source_url`, `fetched_at` и manifest.

## Что требует дополнительной проверки

Локальная выжимка не фиксирует неподтвержденные полные сигнатуры всех `Array*`, `OpenDoc`, `XQuery`, `OpenCodeLib`, методов XML-форм и серверных объектов. Если нужной детали нет в локальном каталоге, следует открыть связанную официальную карточку и подтвердить поведение тестом текущей версии WebTutor.
