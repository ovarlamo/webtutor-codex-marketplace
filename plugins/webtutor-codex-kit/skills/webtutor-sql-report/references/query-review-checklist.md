# Проверка запроса отчёта

- [ ] Контекст и end-to-end тест определены.
- [ ] Все таблицы и поля подтверждены через capability текущего проекта.
- [ ] Выбраны только необходимые столбцы.
- [ ] Диагностическая выборка ограничена.
- [ ] Динамические значения не вставлены как непроверенный текст.
- [ ] Рабочий `XQuery()` использует `sql:`.
- [ ] Диагностический файл содержит чистый `SELECT`, если этого требует tool.
- [ ] Пустой результат обработан до чтения полей.
- [ ] 64-битные ID не проходят через небезопасный `Number`.
- [ ] Read-only SQL-проверка выполнена согласованным способом.
- [ ] Полная связка SQL + SP-XML проверена согласованным end-to-end тестом.
