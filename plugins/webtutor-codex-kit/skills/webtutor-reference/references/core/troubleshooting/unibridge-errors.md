# Unibridge и неинформативные серверные ошибки

## Симптом

Вызов завершается общим сообщением, например об отсутствии ссылки на объект,
без точной строки бизнес-кода.

## Диагностика

1. Прочитать полный JSON-ответ, `errors`, `logs`, `assertions`.
2. Если выполняется SQL через `XQuery()`, проверить `sql:`.
3. Проверить отсутствие результата до обращения к первой строке/полю.
4. Проверить фактические имена и типы полей.
5. Выполнить SQL отдельно через `db-query`.
6. Повторить исходный полный тест.

Не считать общий текст ошибки доказательством конкретной причины.
