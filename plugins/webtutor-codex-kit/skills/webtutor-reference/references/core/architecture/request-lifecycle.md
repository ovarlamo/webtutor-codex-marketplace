# Жизненный цикл запроса

Общая модель для диагностики:

```text
входные параметры
→ проверка и нормализация
→ получение данных
→ преобразование SP-XML
→ сериализация/рендеринг
→ вызывающая сторона
```

При ошибке определить границу, на которой нарушился контракт. Успешный SQL не
подтверждает корректность обработки результата; успешный серверный ответ не
подтверждает корректность браузерного рендеринга.

Для конкретного файла восстановить цепочку по вызывающему коду и тесту. Не
считать эту общую модель доказательством наличия конкретных параметров.
