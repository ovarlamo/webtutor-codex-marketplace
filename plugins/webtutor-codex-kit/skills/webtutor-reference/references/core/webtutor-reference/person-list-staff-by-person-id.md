# Иерархия подразделений сотрудника

## Быстрая подсказка

`tools.person_list_staff_by_person_id()` возвращает строку с иерархией
подразделений сотрудника без его должности.

Чтобы вывести полную цепочку начиная с непосредственного подразделения
сотрудника и далее вверх по иерархии:

```javascript
var subdivision_path = tools.person_list_staff_by_person_id(
    Int(person_id),
    null,
    50,
    '1',
    ' -> '
);
```

Пример результата:

```text
Отдел сотрудника -> Управление -> Департамент -> Организация
```

Значение глубины `50` здесь означает «вся доступная цепочка»: сама реализация
функции ограничивает подъём по иерархии пятьюдесятью уровнями.

## Сигнатура и параметры

```javascript
tools.person_list_staff_by_person_id(
    person_id,
    person_doc,
    depth,
    top,
    separator
)
```

| Параметр | Значение |
|---|---|
| `person_id` | ID сотрудника; передавать как `Integer` |
| `person_doc` | необязательный `TopElem` карточки сотрудника; `null` заставляет функцию открыть карточку по ID |
| `depth` | глубина выводимой цепочки; `0` включает особую ветку полной иерархии |
| `top` | направление расчёта при ненулевой глубине; для вывода с нижнего уровня использовать строку `'1'` |
| `separator` | разделитель названий; пустое значение заменяется на ` -> ` |

## Неочевидное поведение `depth = 0`

В WebTutor при `depth == 0` параметр `top` не используется.
Функция входит в отдельную ветку и всегда выводит полную цепочку сверху вниз.
Поэтому такой вызов не начинает вывод с нижнего подразделения:

```javascript
tools.person_list_staff_by_person_id(Int(person_id), null, 0, '1', ' -> ')
```

Чтобы направление `'1'` применилось, глубина должна быть ненулевой. Для полной
цепочки практически используется `50`.

## Особенность подсчёта глубины

В ветке `top == '1'` цикл использует условие `i <= depth`. Поэтому функция
может вернуть до `depth + 1` элементов. Если требуется вся цепочка, это не
мешает вызову с глубиной `50`; если требуется точное число уровней, нужно
учитывать смещение на один.


В исходнике массив заполняется от непосредственного подразделения сотрудника
к родительским. При `depth == 0` он обходится в обратную сторону без проверки
`top`; при ненулевой глубине и `top == '1'` обход начинается с индекса `0`.

подразделения сотрудника, штатное расписание сотрудника, подразделения снизу
вверх, `person_list_staff_by_person_id`.
