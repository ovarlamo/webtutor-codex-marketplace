# Shared WebTutor core

This layer contains reusable WebTutor/SP-XML knowledge. Documents marked
`universal-core` are cross-version contracts; documents marked `common-core`
are shared documentation whose empirical claims retain their stated evidence
boundaries. In both cases, `verified_on` records where an empirical statement
was observed; it is provenance, not a client selector.

- `webtutor-reference/` — language, APIs, objects, XQuery, official-source map, and generated catalog.
- `architecture/` — execution contexts, data access, and request boundaries.
- `troubleshooting/` — symptom-to-cause notes with explicit evidence limits.
- `playbooks/` — active, repository-parameterized procedures.
- `examples/` — acceptance criteria for promoting code into reusable examples.
- `platform/` — reusable findings about installed WebTutor structures and system reports.
