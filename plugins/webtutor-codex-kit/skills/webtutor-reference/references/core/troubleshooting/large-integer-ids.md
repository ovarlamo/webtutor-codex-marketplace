# 64-битные идентификаторы

## Симптом

ID меняется после передачи в браузер/JSON, сравнение не находит запись или
последние цифры округляются.

## Причина

Идентификатор может превышать безопасный диапазон JavaScript Number.

## Исправление

- в SP-XML использовать `Int`/`OptInt`;
- во внешнем JSON передавать ID строкой;
- не выполнять над ID арифметику;
- сравнивать значения в одном подтвержденном представлении.

После исправления проверить ID с длиной, реально встречающейся в проверенной практике, без
сохранения персональных данных в документации.
