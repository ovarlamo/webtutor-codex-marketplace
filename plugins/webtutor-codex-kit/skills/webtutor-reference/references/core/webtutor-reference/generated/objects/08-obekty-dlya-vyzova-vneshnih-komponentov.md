# Объекты для вызова внешних компонентов

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5791375928854454952).

| `DllWrapper` | Объект DllWrapper предназначен для вызова функций, описанных во внешних библиотеках ( DLL ). Функции должны удовлетворять требованиям, аналогичным требованиям для импорта внешних библиотек в Visual Basic . Для вызова функции из определенной библиотеки необходимо создать экземпляр объекта DllWrapper , что вызовет загрузку библиотеки. | — | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592662) |
