# Выполнение кода

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5620276905286592551).

Карточек: 25.

| Имя | Краткое описание | Источник |
|---|---|---|
| `TaskProgress` | Объект, будучи созданным в произвольном месте выполняемого кода, позволяет задать новый уровень прогресс-индикатора. Прогресс-индикатор может быть отображен в UI, если код вызван с оответвующей опцией. В противном случае факт наличия прогресс-индикатора будет проигнорирован. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782948) |
| `CallCodeUrlFunction()` | Открывает файл, содержащий код и вызывает описанную внутри функцию. Загруженный код никак не кэшируется, при повторном вызове загрузка файла произойдет заново. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782764) |
| `CallServerMethod()` | Вызывает метод (функцию) библиотеки на сервере приложения. У метода должна быть установлена мета-директива "META:ALLOW-CALL-FROM-CLIENT:1". Значения аргументов могут быть переданы либо через массив, либо через стандартный объект, содержащий пары "имя аргумента" - "значения аргумента". Не все типы значений могут быть переданы в серверный метод и возвращены обратно. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782766) |
| `CheckCodePageSyntax()` | Проверяет синтаксис страницы со вставками кода по правилам ASP. В случае неверного синтаксиса вызывает исключение с описанием ошибки. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782768) |
| `CheckCodeSyntax()` | Проверяет синтаксис кода на SP-XML Script. В случае неверного синтаксиса вызывает исключение с описанием ошибки. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782767) |
| `CodeLibraryMethodExists()` | Проверяет наличие метода с определенным именем в v2-библиотеке. Возвращает true или false. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782868) |
| `CodeLiteral()` | Кодирует аргумент как константу JScript. Используется для генерации выражений. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911741) |
| `eval()` | Выполняет код JScript в текущем окружении. Аналогична стандартной функции JScript с таким же именем, но, в отличие от нее выполяняет код на отдельном уровне (переменные, объявленные внутри кода, не будут видны снаружи). См. также InPlaceEval | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911778) |
| `EvalAfterDelay()` | Выполняет код спустя заданный временной интервал. Доступно только на клиентской части приложения. Код выполняется всегда в главном потоке, независимо от того, в каком потоке была вызвана функция EvalAfterDelay(). | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782900) |
| `EvalCodePage()` | Интерпретирует содержимое страницы со вставками кода по правилам ASP. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911779) |
| `EvalCodePageUrl()` | Интерпретирует содержимое страницы по правилам ASP. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911780) |
| `EvalCodeUrl()` | Загружает код на JavaScript из заданного url и выполняет его. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911782) |
| `EvalCs()` | Выполняет код JScript аналогично функции eval (), но внутри т.н. критической секции, что исключает одновременнео выполнение кода из разных потоков. Функция как правило используется для доступа к данным, не являющимся thread-safe, например к глобальным XML-документам. Данной функцией следуетт пользоваться с осторожностью, поскольку глобальная секция является общей для всего приложения. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911783) |
| `ExtEval()` | Выполняет код в заданном окружении. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782753) |
| `ExtractUserError()` | Извлекает из объекта типа Error пользовательскую часть сообщения об ошибке. Если объект не содержит выделенно пользовательской части, возвращается полное описание ошибки. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911788) |
| `GetOptCodeLibrary()` | Находит зарегистрированную v2-библиотеку по имени и возвращает ссылку на нее. Если библиотека с указанным именем не найдена, возвращает undefined. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782867) |
| `InPlaceEval()` | Выполняет код JScript в текущем окружении. В отличие от функции eval () выполяняет код на том же уровне (переменные, объявленные внутри кода, будут видны снаружи), и не позволяет возвращать значение. | [карточка](http://docs.datex.ru/article.htm?id=5665465792879477150) |
| `IsCancelError()` | Проверяет, является ли заданный объект типа Error ошибкой отмены операции . | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878645) |
| `ModalTaskMsg()` | Обозначает текущий статус выполения фрагмент кода с упрощенной индикацией пользователю, начатого путем вызова функции StartModalTask () | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878676) |
| `OpenCodeLib()` | Функция OpenCodeLib() открывает библиотеку v1 . Функция открывает документ либо с расширением XML, содержащий набор методов, и возвращает его корневой элемент, либо с расширением .JS, содержащий функции, возвращает псевдо-документ (псевдо-форму), содержащую те же функции. Действие этой функции похоже на действие функции EvalCodeUrl , но не тождествены ей. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592593) |
| `OpenCodeLibrary()` | Функция OpenCodeLibrary() динамически загружает библиотеку v2 . У динамически загруженной библиотеки v2, в отличие от статически описанной в модуле через &lt;code_source_files&gt;, есть два ограничения: 1. Namespace, указанный в файле, игнорируется. 2. Библиотека должна быть описана в одном файле. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782865) |
| `OptEval()` | Выполняет код JS, который, возможно, завершится с ошибкой, с возвратом заданного значения по умолчанию в случае ошибки. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878696) |
| `RegisterCodeLibrary()` | Динамически регистрирует файл v2-библиотеки, как если бы он был описан в модулк через &lt;code_source_file&gt;. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782866) |
| `SafeEval()` | Выполняет код в безопасном окружении (без доступа к каким-либо глобальным данными приложения). | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782752) |
| `StartModalTask()` | Обозначает запуск длительного фрагмент кода с упрощенной индикацией пользователю. Прогресс выполнения будет обозначаться путем перидического вызова функции ModalTaskMsg () | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878775) |
