# Исследование SQL-таблицы

Если в активном проекте есть `webtutor-codex.json`, предпочитай инструмент `webtutor_get_table_info`. В противном случае, если поля или их типы неизвестны, перед написанием SQL используй указанную в репозитории команду получения структуры базы данных только для чтения. Типичный запасной вариант выглядит так:

```powershell
npm run get-table-info -- table <table_name>
```

Не предполагай, что именно такой скрипт существует: найди реальную команду в инструкциях репозитория или его пакетных скриптах. Запрашивай только метаданные. Сохраняй снимок схемы в репозитории клиента лишь тогда, когда он понадобится повторно; указывай команду, исходную установку WebTutor и дату проверки. Никогда не помещай снимки схем конкретного клиента в общую базу плагина.
