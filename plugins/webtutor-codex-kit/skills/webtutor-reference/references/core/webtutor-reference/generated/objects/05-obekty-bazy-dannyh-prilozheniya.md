# Объекты базы данных приложения

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5791375928854455025).

Карточек: 2.

| Имя | Краткое описание | Связанные элементы карточки | Источник |
|---|---|---|---|
| `Catalog` | Обозначает каталог в базе данных. Обычно доступен как глобальная переменная с именем каталога. Пример каталогов в E-Staff: candidates, vacancies, events. Может быть использован в качестве абстрактного массива (как правило для небольших каталогов): for ( eventType in event_types ) { } | — | [карточка](http://docs.datex.ru/article.htm?id=5791375928854455002) |
| `Database` | Объект, обозначающий базу данных приложения. Обычно доступен в единственном экземпляре через глобальную переменную DefaultDb . | — | [карточка](http://docs.datex.ru/article.htm?id=5791375928854455005) |
