# Преобразование форматов и кодировок

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5620203358492510978).

Карточек: 28.

| Имя | Краткое описание | Источник |
|---|---|---|
| `AdjustUtf8()` | Проверяет строку в UTF-8 на валидность. Если в строке обнаруживается некорректная для UTF-8 последовательность байт, она заменяется на символ '?'. Возвращается исходная либо измененная строка. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782845) |
| `AutoDecodeCharset()` | Функция AutoDecodeCharset() проверяет, является ли строка валидной строкой в кодировке UTF-8. Если да, возвращает саму строку. Если нет, декодирует строку, как если бы она была в однобайтовой кодировке, установленной по умолчанию (обычно windows-1251). Если приложение работает не в кодировке UTF-8, функция возвращает исходную строку без изменений. Функция поддерживается только на сервере или десктопном клиенте. | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454925) |
| `Base64Decode()` | Декодирует данные из формата Base64. Данные возвращаются в виде строки, которая может содержать бинарные данные. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911716) |
| `Base64Encode()` | Кодирует строку в формат Base64. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911717) |
| `DataFromHex()` | Преобразует 16-ричное представление в строку из байт. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782804) |

| `EncodeCharset()` | Переводит строку из кодировки, используемой в программе по умолчанию, в заданную кодировку. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911776) |
| `EncodeMimeHeaderValue()` | Функция EncodeMimeHeaderValue() кодирует строку, которая будет использоваться внутри MIME-заголовка, при условии что содержимое труебует кодирование (наппример, содержит не ASCII символы). Результат имеет вид "=?utf-8?B?&lt;base64data&gt;". Если содержимое строки не требует кодирования, возвращается исходная строка. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782830) |

| `MultipartFormEncode()` | Формирует тело http запроса для последующей отправки методом POST в формате multipart/form-data. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878679) |
| `ParseConfig()` | Функция ParseConfig() преобразует строку в формате конфигурационного файла (.ini) в стандартный объект. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782828) |
| `ParseHeaderPairs()` | Функция ParseHeaderPairs() преобразует строку со значением поля MIME заголовка в стандартный объект, содержащий список вспомогательных параметров. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782829) |
| `RestoreBrokenCharsetEncoding()` | Проверяет строку на некорректную кодировку, вызванную одним из типовых случаев неправильной двойной конвертации. Возвращает новую строку в правильной кодировке, если ее удалось восстановить. В противном случае возвращается undefined. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782846) |
| `RtfEncode()` | Кодирует обычный текст в формат rtf. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878747) |
| `RtfToPlainText()` | Переводит текст в формате rtf в обычный текст. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878748) |
| `SqlLiteral()` | Кодирует значение как константу (литерал) языка SQL. Функция используется при генерированиия выражений на SQL из программы. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878773) |

| `UrlEncodeQueryExt()` | Преобразут объект типа Object в строку вида 'name1=value1&amp;name2=value2&amp;...' для использования в качестве запроса в url. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878834) |
| `Utf16ToUtf8()` | Преобразует строку из формата UTF-16 в UTF-8. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782847) |
