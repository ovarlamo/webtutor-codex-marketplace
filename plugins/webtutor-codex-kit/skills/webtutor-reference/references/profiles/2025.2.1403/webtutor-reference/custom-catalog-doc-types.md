# Создание страниц пользовательского каталога

## Автоматическая страница «Общие сведения»

При генерации пользовательского каталога WebTutor автоматически создаёт в
карточке страницу «Общие сведения». Создавать лист с таким назначением через
`top_elem.sheets.AddChild()` не нужно: принудительное создание приводит к
конфликту с системной страницей.

Поля, которые должны отображаться на странице «Общие сведения», добавляются
без привязки к пользовательскому листу: их `sheet_id` оставляется пустым.

```javascript
add_field(top_elem, "name", "Название", "string", "", true, false, "", false);
```

Через `sheets.AddChild()` создаются только дополнительные предметные страницы,
например «Факторы» или «Вопросы и ответы».

## Имена множественных полей

В описании типа документа имя множественного поля указывается в единственном
числе. WebTutor сам добавляет окончание `s` к имени коллекции в сгенерированной
XML-форме.

Например, описание поля `factor` с `is_multiple = true` создаёт в `TopElem`
коллекцию `factors`. Если назвать исходное поле `factors`, ожидаемой коллекции
`TopElem.factors` не будет.

```javascript
var field = add_field(top_elem, "factor", "Фактор", "string", sheet_id, false, false, "", true);

var row = doc.TopElem.factors.AddChild();
```

## Границы

Правило подтверждено пользователем для агентов создания пользовательских
каталогов в WebTutor 2025.2.1403. Оно не относится к ручному проектированию
обычных XML-форм и другим механизмам создания интерфейсов.
