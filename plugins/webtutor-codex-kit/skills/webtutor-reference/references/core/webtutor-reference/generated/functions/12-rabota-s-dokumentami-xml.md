Аргуметы: docUrl - url документа (String) options - опции, необязательный аргумент (String) | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592603) |

Чтобы сохранить измененный документ, необходимо использовать функцию UpdateUiDoc (а не вызвать метод Doc.Save, как при открытии документа при помощи OpenDoc). | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592591) |

Функция используется для серверных документов, к которым может идти обращение их нескольких потоков одновременно (например, глобальных настроек). Поскольку объект XmlDoc не является thread-safe, менять содержимое глобальных документов нельзя, однако можно заменить документ целиком, соблюдая thread-safety. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782863) |

Установка этого аргумента необходима, чтобы при закрытии документа пользователю было предложено сохранить изменения. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592592) |
