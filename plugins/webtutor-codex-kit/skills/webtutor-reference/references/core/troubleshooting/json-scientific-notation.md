# Экспоненциальная запись чисел в JSON

## Симптом

SQL-запрос успешно возвращает строки, но последующий вызов `ParseJson()` или
`tools.read_object()` сообщает `Invalid JSON`. Диагностический код может
ошибочно представить результат как пустой.

В журнале рядом с указанным смещением находится число в экспоненциальной
форме, например:

```json
{"score":1.500000000000000e+001}
```

## Причина

SQL Server формирует допустимую стандартом JSON экспоненциальную запись для
значений типа `float`. Встроенный `ParseJson()` WebTutor такую запись не
принимает. Это универсальное правило общего ядра; `verified_on` указывает
версию, на которой поведение было непосредственно подтверждено.

## Диагностика

1. Проверить исходный SQL отдельно и убедиться, что строки возвращаются.
2. Записать в журнал строку после `FOR JSON PATH`.
3. Сопоставить offset из `Invalid JSON` с первым числом, содержащим `e` или
   `E`.
4. Убедиться, что ошибка возникает при `ParseJson()` или
   `tools.read_object()`, а не при выполнении SQL.

## Исправление

Если JSON сформирован доверенным SQL-кодом, не разбирать его через
`ParseJson()` только ради повторной сериализации. Передать сформированный JSON
в HTTP-ответ как готовый фрагмент. Метаданные ответа и количество строк нужно
формировать отдельно.

В проверенной диагностической реализации количество элементов вычисляется в
SQL через `OPENJSON`, а массив из `FOR JSON PATH` включается в ответ без
промежуточного разбора средствами WebTutor.

## Подтверждение

На версии из `verified_on` запрос с четырьмя строками и полями `float` в
экспоненциальной форме вызывал `Invalid JSON` в `ParseJson()`. После исключения
промежуточного разбора тот же запрос возвращает все четыре строки, а пустая
выборка возвращает пустой массив.

## Границы

Правило применяется ко всем поддерживаемым версиям WebTutor; текущая запись
`verified_on` сохраняет происхождение имеющегося runtime-подтверждения. Оно
относится к JSON, сформированному SQL Server через `FOR JSON PATH`, и не
означает, что экспоненциальная запись запрещена стандартом JSON или не
поддерживается внешними JSON-парсерами.
