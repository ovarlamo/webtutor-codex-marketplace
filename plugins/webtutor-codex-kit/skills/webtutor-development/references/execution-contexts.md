# Минимальная проверка контекста

Перед изменением ответить по исходникам текущего проекта:

1. Как файл запускается?
2. Откуда приходят параметры?
3. Какие платформенные глобальные объекты доступны?
4. Какой тип результата ожидается?
5. Где сериализуются 64-битные ID?
6. Какой тест проверяет всю цепочку?
7. Каковы подтверждённые публичные пути и URL-схемы?

Полное универсальное описание контекстов принадлежит `$webtutor-reference`.
Конкретные entrypoints, команды и маршруты берутся только из текущего проекта.
