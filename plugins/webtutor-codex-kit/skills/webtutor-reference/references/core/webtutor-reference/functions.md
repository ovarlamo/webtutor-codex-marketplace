# Практический справочник функций

Это приоритетный, а не полный список. Он составлен по официальным категориям и частому использованию в исследованной практике. Примеры показывают форму вызова, подтвержденную проектом; перед применением других аргументов проверять официальную карточку.

## Преобразование и диагностика типов

| Функция | Для чего нужна | Важное замечание |
|---|---|---|
| `String(value)` | явное строковое представление | XML-элемент может отдать скалярное значение |
| `Int(value)` | преобразование в `Integer` | использовать после валидации обязательного значения |
| `OptInt(value[, default])` | необязательное целое | при ошибке/пустом значении обычно позволяет получить `undefined` или default; подтверждать нужный контракт |
| `Real(value)` / `OptReal(...)` | вещественное значение | `Real` отличается от `Integer` |
| `OptDate(value)` | необязательная дата | не считать результат JS `Date` |
| `ObjectType(value)` | имя внутреннего типа | полезно перед сериализацией и обходом коллекции |

## Строки

| Функция | Назначение |
|---|---|
| `StrLen(str)` | длина в байтах, результат `Integer` |
| `StrCharCount(str)` | количество символов |
| `StrContains(str, part)` | проверка наличия подстроки |
| `StrBegins(str, prefix)` / `StrEnds(str, suffix)` | проверка начала/конца |
| `StrLowerCase(str)` / `StrUpperCase(str)` | изменение регистра |
| `StrReplace(...)` / `StrReplaceOne(...)` | замена текста; различие вариантов проверять по карточке |
| `StrSplitToLines(str)` | разбиение на строки |
| `Trim(str)` | удаление краевых пробелов |
| `XQueryLiteral(str)` | безопасный литерал для динамического XQuery |

Критический пример:

```javascript
var bytes = StrLen(text);
var chars = StrCharCount(text);
```

Для UTF-8 эти значения могут различаться.

## Массивы и абстрактные последовательности

| Функция | Типовая роль в проверенной практике |
|---|---|
| `ArrayCount(arr)` | размер поддерживаемой коллекции |
| `ArrayOptFirstElem(arr[, default])` | первый элемент либо безопасное значение |
| `ArrayOptFind(arr, expression)` | первый элемент, подходящий под выражение с `This` |
| `ArraySelect(arr, expression)` | фильтрация выражением с `This` |
| `ArrayExtract(arr, expression)` | проекция полей/значений |
| `ArrayMerge(arr, expression, separator)` | преобразование элементов и склейка |
| `ArrayRange(arr, start, count)` | диапазон; в отчетах используется для paging |

Примеры из принятого в проверенной практике стиля:

```javascript
var first = ArrayOptFirstElem(XQuery(xquery));
var found = ArrayOptFind(items, "This.code==role_id");
var ids = ArrayExtract(items, "This.id");
var page = ArrayRange(items, page_index * page_size, page_size);
```

Строки `expression` исполняются движком SP-XML. Не считать их callback-функциями JavaScript и не внедрять туда непроверенный ввод.

## Объекты и свойства

В проверенной практике используются методы объектов:

| Метод | Роль |
|---|---|
| `GetProperty(name)` | обязательное свойство; отсутствие может быть ошибкой |
| `GetOptProperty(name[, default])` | необязательное свойство |
| `SetProperty(name, value)` | установка свойства |
| `HasProperty(name)` | проверка существования |

Пример безопасного чтения входа:

```javascript
var raw_id = Param.GetOptProperty("ID");
var id = OptInt(raw_id);
```

Не предполагать, что эти методы доступны у любого внутреннего XML-типа: проверить `ObjectType()` или документацию конкретного объекта.

## XML-документы и база данных

| Функция/метод | Роль |
|---|---|
| `XQuery(text)` | выполнение XQuery или запроса с поддерживаемым префиксом |
| `OpenDoc(url)` | открытие XML-документа |
| `UrlFromDocID(id)` | получение URL документа по ID |
| `ObtainChildByKey(...)` | получить либо создать дочерний элемент по ключу |
| `GetOptChildByKey(...)` | получить существующий дочерний элемент либо пустое значение |
| `doc.Save()` | сохранить измененный документ |

```javascript
var doc = OpenDoc(UrlFromDocID(Int(id)));
var top = doc.TopElem;
// изменение полей
doc.Save();
```

Запись в XML-документ требует отдельной проверки схемы и прав. Не добавлять несуществующие поля по догадке.

| `UrlToFilePath(url)` | перевод поддерживаемого URL в путь файла |
| `LoadFileData(path)` | загрузка данных файла |
| `OpenCodeLib(url)` | загрузка библиотеки кода |

## Логи и JSON

В проверенной практике используются `LogEvent`, `ParseJson`, `EncodeJson` и библиотечные `tools.object_to_text` / `tools.array_to_text`. Их доступность зависит от среды и подключенных библиотек.

### Основной серверный журнал `xhttp`

Когда требуется вывести диагностическое сообщение именно в основной журнал
WebTutor, использовать системную функцию `alert(value)`:

```javascript
alert("hello world");
```

Это универсальная системная функция ядра для всех версий WebTutor.
Официальная карточка сообщает, что на сервере сообщение записывается в журнал
`xhttp`: [`alert()`](http://docs.datex.ru/article.htm?id=5620250451197911685).
При запуске `xHttp_64.exe` как приложения сообщение также видно в его
консоли, а основной файл журнала имеет датированное имя вида
`xhttp-YYYY-MM-DD.log`. Не заменять `alert()` на `LogEvent()`, если
пользователь просит именно основной журнал, а не отдельный журнал заданного
типа.

Не писать в лог пароли, токены, содержимое персональных документов и полный вход запроса. Для диагностики логировать тип, ID, этап и короткое безопасное описание.

## Официальные категории функций

Документация группирует API по работе с объектами, типами и кодировками, строками, датами, массивами, файлами, URL, HTML, XML-формами и документами, базой данных, экранами, выполнением кода, Web-сервером и системными задачами. Отдельно выделены экспериментальные и устаревшие функции — их не следует выбирать для нового кода без явной причины.
