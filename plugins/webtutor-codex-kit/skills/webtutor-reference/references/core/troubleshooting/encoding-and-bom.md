# Кодировка и BOM

## Подтверждённый случай

Серверный `remote_action.js`, сохранённый как UTF‑8 без BOM и содержащий
кириллицу, мог неверно интерпретироваться WebTutor. Проявлением была
некорректная кириллица в результатах выполнения файла.

В проверенной практике проблема исправлена добавлением UTF‑8 BOM в начало файла:

```text
EF BB BF
```

После BOM первые байты файла имеют вид:

```text
EF BB BF 66 75 6E 63 74 69 6F 6E ...
         f  u  n  c  t  i  o  n
```

## Доказательство

Историческое исправление в репозитории-источнике добавило BOM перед первым исполняемым токеном серверного файла с кириллическими строковыми литералами. Конкретный клиентский путь и commit не являются частью переносимого правила.

### Серверный ASP

Для проверенного server-side ASP-файла пользователь подтвердил
искажение кодировки без BOM. До исправления файл начинался с байтов
`3C 25`, после добавления UTF-8 BOM — с `EF BB BF 3C 25`.

Это подтверждает то же правило для серверных ASP-шаблонов проверенной версии WebTutor,
которые содержат кириллические строковые литералы или формируют ответ с
кириллицей.

### Агенты создания пользовательских каталогов

Пользователь подтвердил, что серверные агенты WebTutor, создающие
пользовательские каталоги, также должны сохраняться в UTF-8 with BOM для
корректной обработки кириллицы. Правило относится как к точке входа агента,
так и к загружаемым через `EvalCodeUrl()` серверным файлам реализации.

## Переносимое правило

Для серверных WebTutor-файлов `*.asp`, `remote_action.js` и агентов создания
пользовательских каталогов, содержащих кириллицу:

1. сразу создавать и сохранять файл в UTF‑8 with BOM;
2. перед редактированием проверять существующую кодировку и первые байты;
3. не удалять имеющийся BOM при форматировании или массовой обработке;
4. после изменения запускать исходный remote action и проверять фактический
   результат с кириллицей.

В PowerShell наличие BOM можно проверить через:

```powershell
Format-Hex -Path path\to\server-file.asp | Select-Object -First 1
```

Ожидаемое начало: `EF BB BF`.

## Границы

Это подтверждённая практика для `remote_action.js`, серверных ASP-шаблонов и
агентов создания пользовательских каталогов в проверенной версии WebTutor. Не
распространять правило автоматически на браузерные JavaScript-файлы, CSS, SQL,
JSON и другие текстовые форматы: для них сначала сравнить рабочий файл того же
типа и проверить фактический результат.

Не выполнять массовую перекодировку репозитория в несвязанной задаче.
