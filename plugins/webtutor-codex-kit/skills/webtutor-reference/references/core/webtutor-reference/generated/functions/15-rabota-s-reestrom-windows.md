# Работа с реестром Windows

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5620203358492510984).

Карточек: 8.

| Имя | Краткое описание | Источник |
|---|---|---|
| `Опции при вызове функций работы с реестром Windows` | Большинство функций работы с реестром Windows принимают в качестве последнего необязятельного аргумента список опций. Опции задаются в двойственном формате - либо объект типа Object, как праивло описываемый конструкцией JSON, либо строкой вида namr1=value1;name2=value2;... | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454872) |
| `GetSysRegKeyChildNames()` | Возвращает массив имен дочерних ключей заданного ключа реестра Windows. | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454871) |
| `GetSysRegStrValue()` | Возвращает значение строкового из реестра Windows. Если элемент не существует, возвращается пустая строка. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878618) |
| `RemoveEmptySysRegKey()` | Удаляет ключ реестра Windows, если он пустой. Если ключ содержит другие ключи, функция завершается с ошибкой. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878737) |
| `RemoveSysRegKey()` | Удаляет ключ реестра Windows, включая все вложенные ключи. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878738) |
| `SetSysRegIntegerValue()` | Устанавливает целочисленное значение ключа реестра Windows. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878760) |
| `SetSysRegStrValue()` | Устанавливает строковое значение ключа реестра Windows. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878761) |
| `SysRegKeyExists()` | Проверяет существует ли ключ реестра Windows. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878814) |
