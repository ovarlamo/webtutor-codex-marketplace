# Работа с базой данных приложения

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5620276905286592652).

Карточек: 12.

| Имя | Краткое описание | Источник |
|---|---|---|
| `CatalogNameToObjectName()` | Преобразует имя каталога в имя объекта. Фактически функция преобразует имя существительное множественного числа в имя существительное единственного числа по правилам английского языка. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592598) |
| `FetchDb()` | Открывает базу данных и помещает ее в список открытых баз. Если база уже открыта, возвращается ссылка на открытую базу из списка. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592613) |
| `FindOptCatalog()` | Ищет каталог по имени во всех используемых базах данных. Если не находит - возврашает undefined. | [карточка](http://docs.datex.ru/article.htm?id=5665465792879477148) |
| `GetDbFilePath()` | На основании наименования зашифрованной базы данных (модуля) выдает полный путь до зашифрованного модуля базы данных (XFP - файл). Функция не проверяет фактическое существование файла по указанному пути. Аргумент moduleName - наименование базы данных (String) | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592610) |
| `IsPackageDb()` | Выдает true, если указанная база данных находится в зашифрованном модуле (XFP - файл), и false, если не содержит. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592611) |
| `LoadLdsUrlData()` | Аналог функции LoadUrlData (), позволящий явно указать адрес сервера приложения, с котрого будут загружаться данные. Используется как правило для синхронизации данных или обмена данными между несколькими серверами приложений. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592600) |
| `PreloadXQueryResultForeignRecords()` | Функция PreloadXQueryResultForeignRecords() получает на вход массив каталожных записей (например результат XQuery), и для каждого поля с FOREIGN-ARRAY каждой записи, заносит foreign elem в кэш каталога, при условии, что каталог, на который ссылается FOREIGN-ARRAY, имеет модель кэширования discrete. Это ровно то же самое, что делает функция XQuery() с опцией preload-foreign-data на клиентской части приложения. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782869) |
| `PreprocessRecordsByReadAccess()` | Функция PreprocessRecordsByReadAccess() получает на вход массив каталожных записей (например результат XQuery), и для каждой записивыполняет проверку прав доступа текущего пользователя на чтение. Если для записи отстутвуют права доступа, поля записи проходят через обфускацию. Это ровно то же самое, что делает функция XQuery() на сервере, будучи вызванной с клиента. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782870) |
| `SetDbFilePackage()` | Осуществляет загрузку в указанную зашифрованную базу данных (модуль) информации из объекта. Используется, например, при подгрузке интернет-модулей в E-Staff c сайта производителя. Объект, информация из которого может быть загуржена в базу данных, создается специальной командой new FilePackage, после чего в объект помещается информация, например, при помощи метода LoadFromStr . | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592612) |
| `SetDbHostDir()` | Устанавливает директорию, которую программа будет считать местом расположения базы данных. По умолчанию директория называется так же, как и база И располагается в программной директории. Функция используется, если нужно поместить базу в другую директорию. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592609) |
| `XQuery()` | Выполняет заданный запрос XQuery. В сетевой версии приложения запрос выполняется на сервере. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592520) |
| `XQueryLocal()` | Выполняет заданный запрос XQuery на клиентской машине. Используется для запроса данных из каталогов локальных баз данных. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592524) |
