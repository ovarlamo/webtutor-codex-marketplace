# Прочие объекты

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5791375928854454951).

Карточек: 14.

| Имя | Краткое описание | Связанные элементы карточки | Источник |
|---|---|---|---|
| `BackgroundTask` | Объект BackgroundTask предназначен для выполнения кода в отдельном потоке. Код может выполняться как локально, так и на сервере приложения. На клиенте может быть включен прогресс-индикатор. | `Error`, `ErrorDesc`, `ErrorLogName`, `IsRunning`, `MaxProgressLevels`, `OptInnerProgress`, `Progress`, `Result`, `RunAsync`, `RunOnServer`, `ShowProgress`, `CallMethod()`, `Kill()` | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454970) |
| `CsvReader` | Объект CsvReader предназначен для чтения файлов в формате CSV. Объект является более эффективной заменой функции OpenDoc() с опцией "format=csv", поскольку в нем отсутствует промежуточное преобразование в формат XML. Также объект потребляет гораздо меньше памяти, чем функция OpenDoc(). Объект поддерживается только на сервере или десктопном клиенте. | `Delimeter`, `Rows`, `UseXmlRows`, `LoadData()`, `LoadUrl()` | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454921) |
| `HttpResponse` | HttpResponse - это объект, который возвращает функция HttpRequest. Т.е. вызов функции HttpRequest - единственный способ создать объект HttpResponse, в явном виде его создать нельзя. Основной атрибут этого объекта - Body , все остальные используются в редких случаях. | `BinaryBody`, `Body`, `ContentType`, `Header`, `RespCode`, `Url`, `GetHeaderValue()`, `SaveToFile()` | [карточка](http://docs.datex.ru/article.htm?id=5620203358492510993) |
| `ImapClient` | Объект для работы по протоколу IMAP в низкоуровневом режиме. | `UseTLS`, `UseTLSPort`, `Authenticate()`, `OpenSession()`, `RunCommand()` | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782914) |
| `Lock` | Объект Lock предназначен для безопасного одновременного доступа к общим данным из нескольких потоков, если общие данные не являются thread-safe. Как правило, на каждую группу общих данных создается один объект Lock. Создание объекта обычно происходи один раз на старте приложения или библиотеки и хранится в глобальной переменной. | — | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454961) |
| `MailboxReader` | Текстовое описание в исходной карточке отсутствует; карточка содержит перечень связанных элементов. | `Message`, `CloseMailbox()`, `DeleteMessage()`, `MarkMessageAsRead()`, `OpenMailbox()`, `ReadNextMessage()` | [карточка](http://docs.datex.ru/article.htm?id=5620203358492510990) |
| `MethodRunner` | Объект MethodRunner используется внутри ядра для вызова методов, описанных в XMD-форме. Также его можно создать явно через new MethodRunner в случае, если требуется вызвать метод с параметрами, отличных от заданных в описании метода, например вызвать метод асинхронно, или без прогресс-индикатора. | — | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454866) |
| `SmtpClient` | Объект для работы по протоколу SMTP. | `UseTLS`, `UseTLSPort`, `Authenticate()`, `OpenSession()` | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782920) |
| `SqlConnection` | Объект для работы с внешней базой SQL. Используется обычно для интеграций с внешними системами. | — | [карточка](http://docs.datex.ru/article.htm?id=5791375928854455012) |
| `TagReader` | Объект TagReader предназначен для последовательного чтения содержимого в формате HTML (реже - XML). В каждый определенный момент TagReader указывает на некотрый текщий тэг, до которого дошло чтение. Текст, находящий между тэгами, считается безымянным тэгом (атрибут TagName вернет пустую строку). Конструктор объекта содержит единственный аргумент: data - содержимое в формате HTML или XML (string) | `AttrNames`, `Comment`, `CurLineIndex`, `EOF`, `ForceLowerCase`, `IsGroupTag`, `MiscText`, `PlainText`, `RawText`, `TagName`, `TagPos`, `TagStr`, `DeleteOptAttr()`, `ExportCompoundAttc()`, `ExportTag()`, `GetAttr()`, `GetBoolAttr()`, `GetRangePos()`, `GetTagStr()`, `Init()`, … (+11) | [карточка](http://docs.datex.ru/article.htm?id=5620203358492510983) |
| `Thread` | Объект, обозначающий отдельный запускаемый поток (thread). | `IsRunning`, `Param`, `EvalCodeUrl()`, `EvalCode()` | [карточка](http://docs.datex.ru/article.htm?id=5620203358492510992) |
| `ThreadPool` | Объект, обозначающий пул запускаемых потоков, выполняющих идентичный код. Количество работающих потоков может автоматически регулироваться в зависимости от нагрузки. | `MaxThreadCount`, `MinThreadCount`, `TaskHandler`, `ThreadCount`, `Kick()`, `Start()` | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782970) |
| `WebSocketClient` | Клиент для установки websocket-соединения к внешнему ресурсу. Описание Для отладки веб сокетов можно включить журнал "ws", добавив в конфигурационный файл параметр LOG: ws В журнал будут записываться все сообщение, отправленные или полученные через веб сокеты. | `AutoReconnect`, `OnClose`, `OnMessage`, `Close()`, `Connect()`, `SendMessage()`, `SetRequestHeader()` | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782805) |
| `WebSocketServer` | Объект, ссылающийся на установленное websocket-соединения от внешнего ресурса. В отличие от объекта WebSocketClient, WebSocketServer не может быть создан явно через оператор new. Вместо этого используется метод Request.UpgradeToWebSocket() . Это необходимо, в частности, для единообразной проверки авторизации, доступа к веб-сессии, кукам и пр. | `OnClose`, `OnMessage`, `SendMessage()` | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782813) |
