# Диагностика удалённой коллекции

1. Найди в репозитории сквозной тест именно этой коллекции; не меняй его точку доступа только ради диагностики.
2. Воспроизведи ошибку и изучи полный ответ, включая `errors`, логи и результаты проверок.
3. Определи этап возникновения ошибки: параметры → SQL/XQuery → преобразование SP-XML → сериализация → вызывающий код.
4. Проверь неизвестные таблицы и поля SQL с помощью предусмотренного репозиторием способа чтения структуры базы данных.
5. Отдельно выполни запрос через предусмотренный репозиторием механизм SQL только для чтения, ограничив число полей и строк до минимума.
6. Сравни возвращаемые поля и типы с обращениями к ним из SP-XML; отдельно обработай пустой результат и 64-битные идентификаторы.
7. Повторно запусти исходный полный тест коллекции.

Успешное выполнение SQL ещё не доказывает, что удалённая коллекция соответствует своему контракту.
