# Преобразование типов данных

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5620203358492510985).

Карточек: 17.

| Имя | Краткое описание | Источник |
|---|---|---|
| `Compare()` | Функция Compare() сравнивает два произвольных значения. Возращает 0, если значения равны, положительное число, если первое значение больше второго, и отрицательное число, если первое значение меньше второго. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782818) |
| `DataType()` | Возвращает строку, содержащий тип данных переданного значения. Возможные значения: "undefined" "null" "string" "integer" "real" "bool" "date" "object" | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782781) |
| `Int()` | Преобразует значение аргумента к целому числу. Если преобразование выполнить невозможно, возвращает ошибку. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878640) |
| `IsEmptyValue()` | Проверяет, является ли значение undefined, null либо пустой строкой. Позволяет писать универсальный код, не зная точный тип данных переданного аргумента. | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454999) |
| `ObjectType()` | Возвращает тип переданного объекта в низкоуровневом виду. Если переданнве значение не является объектом, возвращает пустую строку. Примеры возможных значений: "JsObject" "JsArray" "XmElem" "XmMultiElemObject" и др. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782782) |
| `OptInt()` | Преобразует значение аргумента к целому числу. Если преобразование выполнить невозможно, возвращает undefined, либо defaultVal, если оно указано. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782783) |
| `OptReal()` | Преобразует значение аргумента к вещественному числу. Если аргумент не может быть преобразован к вещественному числу, функция возвращает undefined, либо defaultVal, если оно указано. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782784) |
| `Real()` | Преобразует значение аргумента к вещественному числу. Если аргумент не может быть преобразован к вещественному числу, функция отрабатывает с ошибкой. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878734) |
| `RValue()` | Возвращает скалярное значение аргумента, если в качестве аргумента передан объект. Если передано скалярное значение, возращается оно же. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878749) |
| `StrHexColor()` | Преобразует 10 обозначение цвета (RGB) в шестнадцатиричное, принятое в формате html. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878782) |
| `StrHexInt()` | Возвращает строку, содержащую аргумент в шестнадцатиричном виде (64 бита). | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878783) |
| `StrInt()` | Преобразует неотрицательный целочисленный аргумент в строку. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878785) |
| `StrIntZero()` | Если значение целочисленного аргумента = 0 преобразует его в "-", иначе в строку (аналогично функции StrInt () ) | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878786) |
| `StrReal()` | Преобразует вещественный аргумент в строку. Если аргумент равен null либо пустой строке, возвращает пустую строку. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878797) |
| `StrRealFixed()` | Преобразует вещественный аргумент в строку. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878798) |
| `StrSignedInt()` | Преобразует целочисленный аргумент в строку. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782785) |
| `TextInt()` | Преобразует целое число в словесное строковое представление. Только для русского языка. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878818) |
