# Работа с датами

| Имя | Краткое описание | Источник |
|---|---|---|
| `Date()` | Конструктор стандартного объекта JavaScript Date . | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911752) |
| `DateDiff()` | Возвращает разницу между 2-мя датами в секундах. Если первая дата меньше второй, разница будет отрицательным числом. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911753) |
| `DateNewTime()` | Изменяет значение времени в заданной дате. Возвращает измененную дату. Если указан только первый аргумент, функция возвращает дату без времени. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911754) |
| `DateNewTimeZone()` | Меняет значение часового пояса внутри даты, оставляя значение времени суток без изменений. Функция обычно используется в локальных вычислениях. При сохранении даты в базе данных или передачи ее по сети информация о хранимом часовом поясе внутри даты может потеряться. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782788) |
| `DateOffset()` | Сдвигает дату на указанное число секунд. Если значение второго аргумента отрицательное, дата сдвигается назад. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911755) |
| `DateToLocalDate()` | Преобразует дату к местному часовому поясу, оставляя глобальное значение даты без изменений. Функция обычно используется в локальных вычислениях. При сохранении даты в базе данных или передачи ее по сети информация о хранимом часовом поясе внутри даты может потеряться. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782791) |
| `DateToRawSeconds()` | Возвращает количество секунд, прошедших с 1970 года до заданной даты. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911756) |
| `DateToTimeZoneDate()` | Преобразует дату к другому часовому поясу, оставляя глобальное значение даты без изменений. Функция обычно используется в локальных вычислениях. При сохранении даты в базе данных или передачи ее по сети информация о хранимом часовом поясе внутри даты может потеряться. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782790) |
| `Day()` | Возвращает значение дня (1-31) для заданной даты. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911757) |
| `GetCurTicks()` | Возвращает время в милисекундах, прошедшее с момента запуска операционной системы. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878597) |
| `GetLocalTimeZone()` | Возвращает местный часовой пояс (integer). | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782792) |
| `Hour()` | Возвращает значение часа для заданной даты. Если дата не содержит времени, возращается undefined. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878629) |
| `IsValidDate()` | Проверяет валидность даты по календарю. Возвращает true или false. Функция IsValidDate() может потребоваться, поскольку не все функции, работающие с датами, имеют встроенную проверку на валидность. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782787) |
| `Minute()` | Возвращает значение минуты для заданной даты. Если дата не содержит времени, возращается undefined. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878674) |
| `Month()` | Возвращает номер месяца (1-12) для заданной даты. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878677) |
| `OptDate()` | Конструирует значение типа date. Возвращает undefined в случае, если указаны недопустимые аргументы. | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454899) |
| `ParseDate()` | Пытается распознать строку с датой в одном из неформальных форматов, например '1 ноября 2011 года'. Возвращает дату. Если распознать дату не удалось, возвращает ошибку. Если строка содержит дату в одном из стандартных форматов, например '2011-11-01' или '01.11.2011', рекомендуется использовать более простую и эффективную функцию OptDate() . | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878704) |
| `ParseMimeDate()` | Преобразует строку, содержащую дату в формате MIME, в дату. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782786) |
| `RawSecondsToDate()` | Преобразует количество секунд, прошедших с 1970 года в дату. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878721) |
| `Second()` | Возвращает значение секунд для заданной даты. Если дата не содержит значения секунд, возращается undefined. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878753) |
| `StrDate()` | Преобразует дату в строку в формате, используемом по умолчанию в операционной системе. Если в качестве аргумента передается null или пустая строка, функция возвращает пустую строку. В качестве второго аргумента может быть передан как стандартный объект options (современная нотация), так и два отдельных булевых аргумента showTime и showSeconds (устаревшая нотация). | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878780) |
| `StrLongDate()` | Преобразует дату в строку в "длинном" формате (со словесным написанием месяца). Если в качестве аргумента передается null или пустая строка, функция возвращает пустую строку. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878790) |
| `StrMimeDate()` | Пребразует дату в формат MIME. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878794) |
| `StrShortDate()` | Преобразует дату в строку, с двухсимвольным форматом года. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878803) |
| `StrTime()` | Преобразует значение времени внутри даты в строку. Если время не содержится внутри даты, возвращается пустая строка. | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878806) |
| `StrXmlDate()` | Преобразует дату в строку в формате, используемом в XML. Если в качестве аргумента передается null или пустая строка, функция возвращает пустую строку. В качестве второго аргумента может быть передан как стандартный объект options (современная нотация), так и булевый аргумента showTime (устаревшая нотация). | [карточка](http://docs.datex.ru/article.htm?id=5620276892448878810) |
| `TimeZone()` | Возвращает часовой пояс, хранимый внтури даты. Если дата не содержит внутри себя часовой пояс, возвращает undefined. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782789) |
| `UtcToLocalDate()` | Преобразует дату из универсального часового пояса в текущий часовой пояс. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592513) |
| `WeekDay()` | Возвращает номер дня недели для заданной даты. (0 - Воскресенье, 1 - Понедельник и т.д.) | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592515) |
| `Year()` | Возвращает значение года для заданной даты. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592525) |
