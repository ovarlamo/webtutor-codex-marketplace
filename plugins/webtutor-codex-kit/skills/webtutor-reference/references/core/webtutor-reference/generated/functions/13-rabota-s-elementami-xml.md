# Работа с элементами XML

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5665465792879477145).

Карточек: 9.

| Имя | Краткое описание | Источник |
|---|---|---|
| `CreateDynamicElem()` | Создает динамический (без привязки к форме) XML-элемент. Созданный элемент не имеет родительского элемента. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592589) |
| `CreateElem()` | Создает XML-элемент заданному по фрагменту формы. Созданный элемент не имеет родительского элемента. Функция используется для управления сложными структурами в оперативной памяти компьютера (как альтернатива javascript object), а так же для формирования XML для внешнего использования. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592636) |
| `CreateElemByFormElem()` | Создает XML-элемент по заданному элементу формы. Созданный элемент не имеет родительского элемента. Редко используемая функция. | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782759) |
| `ExportElemsToStr()` | Загружает массив XML-элементов в строку. Используется для передачи параметров в плагины и другие внешние процедуры. Смотри так же LoadElemsFromStr . | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592638) |
| `FindSampleFormElem()` | Функция FindSampleFormElem() находит шаблонный элемент формы в списке глобальных шаблонных элементов (описанных с атрибутом SAMPLE="1"). Если шаблонный элемент с данным именем не найден, возвращает undefined. | [карточка](http://docs.datex.ru/article.htm?id=5791375928854454997) |
| `GetFailedForeignElem()` | Создает новый пустой элемент массива, не добавляя его в в сам массив. Используется для отработки "битых ссылок" на элементы массива и ссылок на удаленные элементы массива. Смотри так же GetOptForeignElem и GetForeignElem . В текущей реализации массив может быть только каталогом. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592635) |
| `GetForeignElem()` | Выдает целевой элемент массива по значению первичного ключа. Смотри так же GetOptForeignElem . Действие функции несколько отличается от функции ArrayOptFindByKey () за счет поддержки рекурсивных массивов XML-элементов. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592633) |
| `GetOptForeignElem()` | Выдает целевой элемент массива по значению первичного ключа. Если соответсвующей элемент не найден, возвращается undefined. Смотри так же GetForeignElem (). Действие функции несколько отличается от функции ArrayOptFindByKey () за счет поддержки рекурсивных массивов XML-элементов. | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592634) |
| `LoadElemsFromStr()` | Загружает строку в массив XML-элементов. Используется при обработке параметров, полученных от внешних процедур и плагинов. Смотри также ExportElemsToStr . | [карточка](http://docs.datex.ru/article.htm?id=5620276905286592637) |
