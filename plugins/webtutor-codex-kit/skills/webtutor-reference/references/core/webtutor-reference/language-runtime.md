# Язык и среда выполнения

## Типы и сравнения

SP-XML по модели типов ближе к VBScript, чем к JavaScript:

- `Integer` и `Real` различаются;
- строка и дата являются скалярными значениями;
- дата может содержать или не содержать время, отдельного типа для этих случаев нет;
- дата/время хранятся структурированно, часовой пояс хранится отдельно; SQL-хранилище может внести преобразование к типу СУБД;
- XML-объект может участвовать в операции своим скалярным значением;
- `undefined`, `null`, `""`, `0` и `false` не взаимозаменяемы.

Для входных параметров предпочтительны явные преобразования:

| Задача | Типичный инструмент |
|---|---|
| необязательное целое | `OptInt(value[, default])` |
| обязательное целое после проверки | `Int(value)` |
| необязательное вещественное | `OptReal(value[, default])` |
| строковое представление | `String(value)` |
| определение фактического типа | `ObjectType(value)` |

Не добавлять второй аргумент или трактовку ошибки по аналогии: конкретную сигнатуру нужно подтвердить документацией либо существующим тестируемым вызовом.

## Строки

Строка может содержать текст и бинарные данные. Текст хранится в кодировке приложения (`AppCharset`, обычно UTF-8).

| Требуется | Использовать | Не путать с |
|---|---|---|
| длина в символах | `StrCharCount()` | `StrLen()` возвращает байты |
| первые символы | `StrLeftCharRange()` | `StrLeftRange()` работает с байтовым диапазоном |
| поиск/проверка текста | `StrContains`, `StrBegins`, `StrEnds` | методами JS `includes`, `startsWith`, `endsWith` без проверки поддержки |
| очистка краев | `Trim()` | предположением о наличии `String.prototype.trim` |

## Массивы и последовательности

Официальный индекс базовых объектов включает `Array`, `PlainSeq`, `SafeArray`, `ClassObjectsArray`; результаты `XQuery()` и XML-формы могут возвращать другие последовательности.

В проверенной практике встречаются значения `ObjectType()`:

- `JsArray` — стандартный массив;
- `JsObject` — стандартный объект;
- `XmElem` — XML-элемент;
- `XmLdsSeq` — XML/результирующая последовательность.

Этот список не полный. В ветвлении по типу всегда предусматривать безопасную обработку неизвестного значения.

Функции `ArraySelect`, `ArrayOptFind`, `ArrayExtract`, `ArrayMerge` часто принимают строковое SP-XML-выражение с `This`. Это исполняемый код, а не JS callback:

```javascript
var active = ArraySelect(items, "This.is_active==true");
var ids = ArrayExtract(active, "This.id");
```

Не вставлять в такое выражение непроверенный пользовательский текст.

## Модули и URL

Платформа использует собственные URL-схемы и модульную структуру. Официальная документация рекомендует в новой объектной модели адресацию `x-app://...`; старые приложения применяют `x-local://...`. Конкретный проект может использовать `x-app://...` или `x-local://...`; схему и `<custom_root>` нужно получить из его рабочего кода или конфигурации.

Сохранять существующую схему проекта, пока миграция не поставлена отдельной задачей. URL собирать через `UrlAppendPath()`, библиотеку открывать через `OpenCodeLib()`.

```javascript
var lib_url = UrlAppendPath("x-local://wt/web/<custom_root>/libs", "common.js");
var common = OpenCodeLib(lib_url);
```

Не подменять платформенный URL путем Windows и не использовать ручную конкатенацию разделителей.
