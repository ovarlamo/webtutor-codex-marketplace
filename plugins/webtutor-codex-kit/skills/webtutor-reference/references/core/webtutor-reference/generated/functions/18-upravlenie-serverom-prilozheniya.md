# Управление сервером приложения

Источник категории: [docs.datex.ru](http://docs.datex.ru/article.htm?id=5620203358492510994).

Карточек: 6.

| Имя | Краткое описание | Источник |
|---|---|---|
| `DaemonGetState()` | Определяет статус зарегистрированного сервера приложения (службы Windows). Значения статуса: 0 - сервер выключен 1 - сервер включен 2 - сервер начинает работу 3 - сервер завершает работу | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911748) |
| `DaemonGetStateParam()` | Возвращает значение параметра, обозначающее текущй статус задачи, выполняемой при старте сервера, например перестройки фалов каталога или конвертации данных из предыдущей версии программы. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911749) |
| `DaemonStart()` | Включает установленный сервер. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911750) |
| `DaemonStop()` | Выключает установленный сервер. | [карточка](http://docs.datex.ru/article.htm?id=5620250451197911751) |
| `RegisterDaemon()` | Регистрирует серверную службу (только Windows). | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782850) |
| `UnregisterDaemon()` | Удаляет зарегистрированную службу (только Windows). | [карточка](http://docs.datex.ru/article.htm?id=7172076235998782852) |
